# 路线图

记录“接下来做什么、先做哪个、做到什么算完成”。它回答的是方向和顺序；已经发生的变化看 [CHANGELOG](../CHANGELOG.md)，为什么这样设计看 [ADR](adr/README.md)，每次任务的过程看[开发日志](devlog/README.md)。

- 基线：2026-11-11 对 v0.2 的一次核对（86 个测试通过、ruff 通过、`web/dist` 与源码一致、main 上 CI 成功；真实模型未实测）。核对发现的问题和设计文档里尚未实现的部分，按下面四档排序。
- 排序依据：先修“已经承诺但实际不成立”的（P0），再补“单用户版放心用”缺的（P1），然后是“多用户与正式部署”的前提（P2），最后是能力扩展（P3）。
- 维护方式：开始做一项时把状态改为“进行中”，完成后改为“已完成”并填上版本和开发日志；新发现的问题按同样的标准插入对应档位。条目编号不复用。P2、P3 的条目动手前先写 ADR。

状态取值：计划 / 进行中 / 已完成 / 搁置（写明原因）。

## P0 已承诺但不成立

| 编号 | 事项 | 完成标准 | 状态 |
| --- | --- | --- | --- |
| P0-1 | **浏览器来源校验**。`/ws/workbench`、`/ws/bridge` 不校验 `Origin`：用户浏览器里的任意网页都能连上工作台通道，发起任务并自己回 `confirm_decision`，写操作确认形同虚设（已复现：外来来源完成了一次调度系统提交）。 | 外来来源的 WebSocket 握手和会改状态的 HTTP 请求被拒绝；工作台、清单里的系统页面、命令行不受影响；有回归测试；ADR | 计划 |

## P1 单用户版放心用

| 编号 | 事项 | 完成标准 | 状态 |
| --- | --- | --- | --- |
| P1-1 | **预览之后数据变了要拦住**。提交时系统重新计算变更，不校验预览时的数据版本；用户确认的清单可能和实际提交的不一样。 | 新接入规则：预览返回版本、提交带回、不一致时系统拒绝；网关把它转成明确的错误并作废令牌；调度系统样例实现；测试；ADR | 计划 |
| P1-2 | **模型调用健壮性**。模型接口返回 429 / 5xx 或连接失败时不重试；发给模型的历史只按条数（60）裁剪，不看长度；没有用量统计。 | 可配置次数的退避重试（已开始输出后不重试）；历史按估算的 token 预算裁剪；运行结束事件带用量，工作台显示 | 计划 |
| P1-3 | **真实模型对照评测**。历次开发日志都写着“真实模型：没运行”，模型路径只由假的 OpenAI 兼容接口覆盖。 | 一条命令，用各系统场景剧本的示例对照规则模式与配置的模型（工具序列、步数、是否走到确认），输出报告；评测本身有测试。真实模型的结果在有密钥的环境运行后记入开发日志 | 计划 |
| P1-4 | **审计与数据留存**。审计面板只读内存，重启后为空；`audit.jsonl` 不轮转；结果文件和内存里的结果过期后不清理；确认令牌表只增不减。 | 启动时从文件恢复最近的审计记录；审计文件按大小轮转（不删除）；过期结果从内存和磁盘清理；过期令牌清理 | 计划 |
| P1-5 | **意图识别可观测**。没识别到的提问没有汇总，补剧本没有依据；工作台不显示识别结果。 | 每次运行的识别结果落盘，接口可查未识别的提问和命中率；工作台在执行过程处显示“识别为：…” | 计划 |
| P1-6 | **发版 v0.3.0**。“未发布”里有破坏性改名；ADR-0011 已合并但状态仍是“提议”。 | ADR-0011 改为已采纳；版本号、CHANGELOG、文档标题落成 0.3.0 | 计划 |

## P2 多用户与正式部署

动手前先写 ADR；身份和持久化互相牵连，建议合并讨论。

| 编号 | 事项 | 说明 | 状态 |
| --- | --- | --- | --- |
| P2-1 | 身份与权限 | 接 SSO（从令牌解析用户，替换 `AGENT_DEFAULT_USER`）；调用系统时做令牌交换（`auth.mode: token_exchange`）；按角色过滤工具；`critical` 二次确认 | 计划 |
| P2-2 | 持久化 | 确认令牌在进程内存，重启即作废；对话是全量载入内存的 JSON 文件；结果仓库是内存 + 文件。换成数据库 / 缓存，接口不变 | 计划 |
| P2-3 | 部署与运维 | 容器镜像与编排文件；健康检查端点；链路追踪（OpenTelemetry）；审计外送 | 计划 |
| P2-4 | 前端质量 | `store.ts`（事件重放的 reducer）的单元测试；桥接 SDK 的自动化测试；CI 里的浏览器冒烟；前端 lint；JS 单包 1.4 MB 按页签拆分 | 计划 |
