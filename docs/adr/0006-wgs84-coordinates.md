# ADR-0006 平台坐标统一 WGS84

- 状态：已采纳
- 日期：2026-10-28（2026-10-29 补记）
- 相关：AGENTS 约束 5、INTEGRATION_RULES R7.1、清单字段 `crs`

## 背景

接入的多为类 GIS 系统，国内系统常用 GCJ-02、BD-09 或 CGCS2000。坐标在系统之间传递（车队位置 → 分组 → 地图叠加）时，如果混用坐标系，点位会偏移几百米，而且很难从数据本身看出来。

## 决策

- 工具的输入输出统一 WGS84（`crs: EPSG:4326`，清单中只能填这个值），几何用 GeoJSON，坐标顺序 [经度, 纬度]。
- 系统内部使用其他坐标系时，在系统接口或 `adapter_hooks.py` 钩子里转换，平台和模型不接触非 WGS84 坐标。

## 考虑过的其他方案

- 每个结果携带坐标系、由网关按需转换：平台要维护多种转换，还要求所有工具都正确标注，出错面更大。

## 后果

- 好处：结果仓库、内置分组、工作台点位预览都只处理一种坐标；跨系统传递无需判断。
- 代价：非 WGS84 系统接入时要写转换。
- 后续：无。
